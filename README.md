# Fahrtenbuch

Android-App (ab Android 8) zur Fahrtenerfassung in einer lokalen Excel-Datei (.xlsx).

Build: GitHub Actions (.github/workflows/build.yml) erzeugt bei jedem Hochladen die signierte APK
als Artefakt „Fahrtenbuch-APK“.

Signaturschlüssel: app/fahrtenbuch.jks; Repository privat halten. Gleicher Schlüssel ermöglicht
Updates ohne Deinstallation.
